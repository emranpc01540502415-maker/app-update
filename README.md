# ভয়েস অ্যালার্ট (Android)

## GitHub থেকে APK বানানোর নিয়ম
1. GitHub-এ repository খুলে এই ফোল্ডারের সব ফাইল (লুকানো `.github` সহ) আপলোড করুন।
2. **Actions → Build APK → Run workflow** চালান (push করলেও নিজে চলবে)।
3. শেষ হলে **Artifacts → VoiceAlert-APK** নামিয়ে `app-debug.apk` ইনস্টল করুন।

## সবসময় চালু রাখতে (একবারই করতে হবে)
অ্যাপ খুলে উপরের চেকলিস্টে **"অনুমতি দিন"** চাপুন → সব অনুমতি ও "ব্যাটারি সীমাবদ্ধতা মুক্ত" দিন →
**"অটো-স্টার্ট"** চেপে অ্যাপটির অটো-লঞ্চ/ব্যাকগ্রাউন্ড অ্যাক্টিভিটি চালু করুন।
সম্ভব হলে রিসেন্ট অ্যাপ স্ক্রিনে অ্যাপটি "লক" করে রাখুন।

## ইসলামিক ফিচার
নামাজের সময় (অফলাইন গণনা), আজান/ভয়েস রিমাইন্ডার, ওয়াক্তের আগে রিমাইন্ডার, জুমা, সেহরি-ইফতার,
সকাল-সন্ধ্যার জিকির, হিজরি তারিখ, কিবলা কম্পাস, ডিজিটাল তাসবিহ।
আজানের জন্য নিজের পছন্দের আজানের অডিও ফাইল (mp3 ইত্যাদি) বেছে নিন।
